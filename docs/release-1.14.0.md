## GVL Media Studio 1.14.0

Lade `GVL-Media-Studio.exe` herunter, schließe OBS, starte die Datei und klicke auf **Installieren** oder **Aktualisieren**. Mehr braucht es nicht. Wer 1.9.0 oder neuer hat, aktualisiert direkt im Panel über **Jetzt aktualisieren**.

Download `GVL-Media-Studio.exe`, close OBS, run it and click **Install** or **Update**. Nothing else is needed. With 1.9.0 or newer, update right in the panel with **Update now**.

### Neu

- Eine einzige Datei: `GVL-Media-Studio.exe` enthält das ganze Programm und funktioniert allein heruntergeladen, ohne ZIP und ohne Ordner
- Die ZIP bleibt im Release für die automatischen Updates und funktioniert entpackt genauso
- Beim Update wird der alte Programmordner `_internal` aufgeräumt

### New

- A single file: `GVL-Media-Studio.exe` contains the whole program and works on its own, without a ZIP or folder
- The ZIP stays in the release for automatic updates and works the same way when extracted
- Updating removes the old `_internal` program folder
