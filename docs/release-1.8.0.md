## GVL Media Studio 1.8.0

Lade `GVL-Media-Studio.zip` herunter, entpacke die Datei, schließe OBS und starte `Installieren.bat`. Die Anleitung steht im [README](../../blob/main/README.md).

Download `GVL-Media-Studio.zip`, extract it, close OBS and run `Installieren.bat`. See the [English README](../../blob/main/README.en.md) for the full guide.

### Enthalten

- Match-Grafiken direkt aus dem Spiel
- Stream Starting Soon, Gleich zurück und Stream-Ende
- Stream-Plan mit den kommenden GVL-Spielen
- Kommentatoren, eigene Bauchbinden und Laufband
- 3D-Replay im Spiel und Video-Replay über OBS
- Panel auf Deutsch und Englisch
