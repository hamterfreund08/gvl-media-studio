## GVL Media Studio 1.9.0

Lade `GVL-Media-Studio.zip` herunter, entpacke die Datei, schließe OBS und starte `GVL Media Studio.exe`. Im Fenster auf **Installieren** oder **Aktualisieren** klicken.

Download `GVL-Media-Studio.zip`, extract it, close OBS and run `GVL Media Studio.exe`. Click **Install** or **Update** in the window.

### Neu

- Updates direkt im Panel: Gibt es eine neue Version, erscheint oben ein Hinweis mit **Jetzt aktualisieren**
- Neues Fenster für Installieren, Aktualisieren, Reparieren und Deinstallieren, auch über **App öffnen** im Panel
- Die Version steht jetzt oben im Panel
- Fester Port 40231, damit Windows ihn nach einem Neustart nicht mehr blockiert

### New

- Updates right in the panel: when a new version is out, a notice with **Update now** appears at the top
- New window to install, update, repair and uninstall, also via **Open app** in the panel
- The version is now shown at the top of the panel
- Fixed port 40231 so Windows no longer blocks it after a restart
